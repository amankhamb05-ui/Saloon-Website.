# Beauty Salon Website

A responsive, modern Beauty Salon website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — main website
- `css/style.css` — all styling and responsive design
- `js/script.js` — mobile navigation and contact form behavior
- `assets/` — place your images, logo and other media here

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files while keeping the folder structure.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide your website URL.

## Before publishing

Replace these placeholders in `index.html`:

- `ADD PHONE NUMBER`
- `ADD SALON ADDRESS`
- `ADD OPENING HOURS`

You can also add salon photos inside `assets/` and update the hero/gallery sections.

## Pricing

The website uses the supplied Beauty Salon price list as its source content.
